# Housing price prediction

A simple machine learning project based on the third edition of Aurélien
Géron's _Hands-On Machine Learning with Scikit-Learn and PyTorch_. The goal is
to explore housing data and build a model for predicting house prices.

## Running locally

```bash
make setup
make jupyter
```

Alternatively, run the project with Docker:

```bash
make docker-build
make docker-jupyter
```
